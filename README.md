# REVIBE ’26

Official Website for **REVIBE ’26**, a **National Level Symposium** organized by the **Student Guidance Cell (SGC), CAHCET**.

## 🕷️ Theme

The official website theme for **REVIBE ’26** is **SPIDER-MAN**.

The website design, visuals, animations, and overall user experience will follow a **Spider-Man inspired theme** while maintaining a professional symposium identity.

## 🚀 Features

* Modern Spider-Man themed landing page
* REVIBE ’26 symposium information
* Technical & Non-Technical Events
* Event details and rules
* Online Event Registration
* Event-based Registration Fees
* UPI / GPay Payment Flow
* Registration Confirmation
* Venue & Event Information
* Announcements & Updates
* Admin Dashboard
* Fully Responsive UI

## 🛠️ Tech Stack

* React
* Vite
* JavaScript / JSX
* Tailwind CSS
* Framer Motion
* React Router DOM
* Supabase
* PostgreSQL

## 📝 Registration

Participants can register for the available REVIBE ’26 events through the website.

Registration will include:

* Participant details
* Event selection
* Event-specific registration fee
* UPI / GPay payment
* Registration confirmation

The registration fee may vary depending on the event.

## ⚙️ Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

**Supabase** will be used for:

* PostgreSQL database
* Participant registrations
* Event information
* Registration & payment status
* Admin authentication
* Admin management

## 🔐 Admin Dashboard

A separate protected admin dashboard will be developed for managing the REVIBE ’26 website and registration data.
